Student Performance Analytics System

Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student marks and generates a performance report. It calculates total marks and averages, assigns grades, checks pass/fail status, identifies top-performing students, and summarizes class and subject performance.

Objectives
- Analyze student academic performance using Python.
- Organize student records using Pandas.
- Perform numerical calculations using NumPy.
- Identify the highest- and lowest-performing students.
- Calculate subject-wise averages and the overall class average.
- Generate grades, pass/fail results, and a top-five student list.

Technologies Used
- Python
- NumPy
- Pandas
- CSV dataset

Dataset
The project uses students.csv, which contains 20 student records with the following fields:
- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- Data Science marks
- Attendance

Features
1. Calculates each student's total and average marks.
2. Assigns grades based on average marks.
3. Determines pass/fail status based on marks in all three subjects.
4. Identifies the highest- and lowest-performing students.
5. Calculates the overall class average.
6. Calculates subject-wise average marks and identifies the best-performing subject.
7. Displays the top five students.
8. Summarizes the number of students who passed and failed.

How to Run
1. Install Python.
2. Install the required libraries:
   python -m pip install numpy pandas
3. Keep main.py and students.csv in the same folder.
4. Open a terminal in the project folder.
5. Run:
   python main.py

Expected Outcome
The program generates a student performance report containing totals, averages, grades, pass/fail results, subject-wise statistics, class average, and the top five students.

Learning Outcomes
This project provides practical experience with Python functions, loops, conditional statements, NumPy calculations, Pandas DataFrames, CSV file handling, and data analysis.
